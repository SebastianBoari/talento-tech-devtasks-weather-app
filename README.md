DevTask & Weather - Starter

Mini dashboard para webinar: muestra clima usando Open-Meteo y gestiona tareas con localStorage.

Instrucciones rápidas:
1. Abrir `index.html` en un navegador moderno (no requiere servidor).
2. En "Clima" ingresar una ciudad (ej: Buenos Aires) y presionar "Consultar".
3. En "Tareas" agregar tareas; se persisten en `localStorage`.

Notas para el instructor:
- API usada: Open-Meteo (geocoding + current_weather) sin API key.
- Foco: eventos DOM, `fetch` con `async/await`, `try/catch`, `localStorage`.

Extensiones sugeridas: modo oscuro persistente, geolocalización, filtros de tareas, prioridad.
